# liquid_flutter_reactive_forms

A companion package to [`liquid_flutter`](https://pub.dev/packages/liquid_flutter)
that provides extensions for [`reactive_forms`](https://pub.dev/packages/reactive_forms).

## Getting started

Add the package to your `pubspec.yaml`:

```yaml
dependencies:
  liquid_flutter_reactive_forms: ^0.1.0
```

## Usage

Import the package and use the reactive form widgets alongside your existing
`liquid_flutter` UI:

```dart
import 'package:liquid_flutter_reactive_forms/liquid_flutter_reactive_forms.dart';
```
